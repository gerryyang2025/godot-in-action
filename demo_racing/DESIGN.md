# Infinite Racer

`Infinite Racer` 的目标不是复刻真实赛车，而是围绕“极速闪避”做一个可运行、可迭代的玩法原型。它借鉴移动端街机竞速里最抓人的那部分节奏：高速迫近、贴尾、最后一拍切出、安全感瞬间归零，再用一段无敌的大车接管把局势重新拉回来。

## 首版概念

玩家驾驶一台未来风跑车，在五车道高速公路上不断向前冲刺。车流默认全部比玩家慢，所以危险不在超不过去，而在什么时候切线、什么时候赌一次险超、什么时候把跳跃留给大型车辆。燃油会持续下降，逼着玩家主动靠近车尾拿回补，而不是保守地远距离绕行。

## 核心循环

1. 高速靠近慢车尾部。
2. 在即将追尾前切出当前车道，触发一次险超。
3. 用险超连击换分数和燃油续航。
4. 吃到隐身道具后直接穿车，把 Combo 链快速抬高并触发高连击节油。
5. 车阵开始变厚时，寻找大型车辆并完成一次劫持。
6. 回合结束后把 credits 投入改装和进阶，再去冲更远距离。

## 首版范围

- 视角：单机 3D 第三人称追尾视角。
- 赛道：无限循环的五车道高速公路。
- 玩家：1 台跑车，支持左右切线和起跳。
- 交通：普通轿车、服务车辆、大型车辆三类，占用 1 条车道。
- 状态：开始页、进行中、结算页。
- 资源系统：燃油、分数、距离、Combo、credits、车辆等级、三项升级。

## 当前实现状态

当前版本已经不是纯原型骨架，而是一个可完整游玩的玩法切片。以下内容已经落地：

- 五车道高速追尾视角、循环道路、基础环境装饰和宽视野相机。
- 首页、HUD、结算页和轻量车库信息展示。
- 贴尾险超、Combo 累积、分数增长和燃油回补。
- 按 Combo 数量递进的爆字、屏幕闪色与英语语音鼓励。
- 高连击触发的短暂无油耗窗口。
- 劫持大型车辆后的直接接管、免油耗、撞飞清障和结束缓冲护盾。
- 隐身道具拾取、透明化表现、穿车判定和隐身穿车 Combo。
- 普通碰撞改为减速恢复而非立即结束，真实失败条件只保留为燃油耗尽。
- credits、三项升级、`C -> B -> A -> S -> T` 晋升和存档。

## 当前玩法基线

- 游戏开始：从首页进入一局，玩家默认位于五车道中央车道，车辆属性由当前车阶和升级决定。
- 生存目标：尽量维持燃油不见底，同时通过险超、隐身穿车和劫持阶段抬高分数与里程。
- 失败条件：本局只有在燃油耗尽时才会进入结算页；碰撞只会造成减速和连击中断。
- 输入约束：`Space` 只负责跳跃 / 劫持，不再承担重新开始等其他职责。
- 劫持逻辑：若成功接管大型车辆，玩家控制对象会切换到该大车，原玩家车不会以独立实体继续前进。
- 隐身表现：隐身后玩家车进入高透明状态，主要通过轮廓高光和发光件保持可读性。
- 车流节奏：中后期会提高压迫感，但当前版本已经通过活跃数量上限、间距和波次限制避免过度拥堵。

## 关键机制取舍

- 险超不做“擦边体积”判定，而是强调“先贴尾，再切线”的时机窗口；这样更贴近原型目标，也更容易持续调参数。
- 跳跃默认不提供通用越车能力，主要作为“劫持大车”的确认动作，避免玩家把任何拥堵都用跳跃跳过去。
- 普通碰撞不再直接结束回合，而是转成一次明显的掉速与连击中断；这样失误有代价，但不会把节奏直接打断到结算页。
- 大车劫持期间会短暂无敌且不耗油，还允许撞飞前车，让它成为明确的续航与破阵策略，而不是普通的得分特效。
- 隐身道具不是纯保命按钮，而是“穿车堆连击”的强化窗口；它既降低操作门槛，也鼓励玩家主动把节奏拉高。
- Combo 反馈不只显示数字，而是用阶梯式文案、音效和屏幕特效持续鼓励玩家把连击往更高档位推。
- 升级和进阶全部放在开局前的轻量车库 UI 中，用键盘就能完成，不引入额外菜单层。

## 暂不覆盖

- 真实车辆物理、漂移、刹车、氮气和碰撞损伤细分。
- BOSS 关卡、任务链、剧情和多地图切换。
- 更高保真的外部商业车辆、角色动画、音效包和完整 UI 风格还原。
- 复杂敌车 AI，如并线、急刹、同屏追击或警车系统。

## 当前美术取向

- 玩家车与车流已经从纯几何占位体升级为 Quaternius CC0 车辆模型的轻量写实表达。
- 视觉上刻意把交通分成三种轮廓：低矮轿车、较高的服务车、可劫持的大型车辆，保证高速状态下也能快速读清类型。
- 赛道两侧用路灯、交通信号灯和路牌替换了大量纯盒体装饰，让高速公路更像一个真实场景，而不是功能性占位。
- 在第三方模型之上叠加街机化灯条、尾翼、劫持标记和高对比配色，让玩法信息优先级高于纯写实。

## 当前音频与反馈基线

- 背景音乐已接入外部曲目，进行中会持续播放。
- 已实现发车、跳跃、险超、劫持、隐身拾取、升级、晋升、碰撞和燃油耗尽音效。
- Combo 英语语音目前按档位依次为 `GOOD / COOL / GREAT / PERFECT / WELL DONE / WONDERFUL / EXCELLENT / AMAZING / UNBELIEVABLE / I LOVE YOU`。
- 开局会额外播报一次 `GO GO GO`，帮助建立街机化开场节奏。

## 后续可扩展方向

- 增加 BOSS 关卡、主题化赛道或里程阶段事件。
- 给不同车阶加入独特技能，而不仅是单纯数值强化。
- 扩充隐身之外的功能道具，例如短时磁吸燃油、护盾或爆发加速。
- 继续细化音频混音、语音节奏和 HUD 动效，让高连击反馈更有层次。
