# Support

This repository is a personal Godot learning/demo workspace.

## Getting Help

- For this repository's demo code: open a GitHub issue with the relevant directory, Godot version, reproduction steps, and expected behavior.
- For Godot Engine usage: prefer the official Godot documentation and community channels.
- For bugs in copied or locally cached upstream material: report to the upstream project.

## Before Asking

Please check:

- `README.md` for repository layout.
- `AGENTS.md` for repository rules and version boundaries.
- `PLAN.md` for the current 2D demo roadmap.
