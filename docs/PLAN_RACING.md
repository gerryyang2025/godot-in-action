# Racing Demo 详细计划

本文件记录 `demo_racing/` 的当前实现边界，以及后续继续打磨时最值得优先推进的方向。

## 当前定位

`demo_racing/` 是一个面向 Godot `4.6.2` 的独立 3D 竞速闪避 demo。它的目标不是写实赛车，而是围绕“高速闪避、险超补油、卡车劫持、车辆成长”做一个可持续扩展的玩法基线。

## 已完成首版

- 已创建独立顶层项目：`demo_racing/`
- 已完成基础高速路和三车道视角
- 已完成普通车 / 厢车 / 卡车三类车流占位体
- 已完成基于官方 `truck_town` 资源的真实车辆视觉升级
- 已完成险超判定、Combo、燃油回补和分数结算
- 已完成卡车劫持状态：短暂无敌且不消耗燃油
- 已完成轻量车库：credits、三项升级和 `C -> B -> A -> S -> T` 晋升
- 已完成 `README.md`、`DESIGN.md` 和 `REFERENCES.md`

## 推荐下一步

1. 调整车流刷新与险超窗口参数，让前 `30` 秒更平滑、后 `60` 秒更压迫。
2. 为卡车劫持补上更明确的视觉反馈，例如上车瞬间闪白、尾焰变化和屏幕边缘提示。
3. 给 HUD 增加更直观的燃油 / 连击 / 劫持状态样式，减少纯文字依赖。
4. 补充音频：引擎升频、险超提示、劫持命中、结算音效。
5. 考虑加入阶段事件，例如封路车阵、维修无人机、里程碑奖励或轻量 BOSS 车队。

## 验收基线

- 可以从开始页进入回合，并在结束后稳定重开
- 玩家能稳定完成左右变线和卡车劫持
- 险超会稳定回补燃油并累积 Combo
- credits、升级和等级会持久化到 `user://demo_racing_save.cfg`
- 不依赖外部商业素材，仍能保持完整可玩的原型闭环
