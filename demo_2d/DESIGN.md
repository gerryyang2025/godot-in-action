# Signal Sweep

`Signal Sweep` 是一个 Godot 4.6.2 目标版本的俯视 2D 小型 demo。玩家驾驶一艘小型信标回收船，在固定屏幕的训练场里收集发光信标，同时躲开不断增多的巡逻无人机。

## 首版概念

玩家是一名训练中的信号回收员。训练场里的信标会一次出现一个，玩家需要快速靠近并回收它。每回收一个信标，系统会在竞技场里投放新的信标，并周期性增加一架巡逻无人机。无人机会在边界内弹射移动，形成越来越密的危险航线。玩家有 3 点护盾，被无人机撞到会损失护盾并获得短暂无敌。目标是在倒计时结束前回收指定数量的信标。

## 首版范围

- 核心动词：移动、收集、躲避。
- 视角：俯视固定竞技场。
- 玩家：1 个可移动的 `Area2D` 飞船。
- 收集物：1 个当前信标，收集后立刻刷新到新位置。
- 障碍：若干巡逻无人机，沿直线移动并在竞技场边界反弹。
- UI：信标数、护盾数、倒计时、状态提示。

## 胜负条件

- 胜利：在倒计时归零前回收 `8` 个信标。
- 失败：护盾归零，或倒计时归零但信标没有收集完成。
- 重开：游戏结束后按 `Space` 或 `Enter`。

## 操作

- 移动：`WASD` 或方向键。
- 开始/重开：`Space` 或 `Enter`。

## 设计约束

- 首版不使用外部美术、字体或音频资产。
- 首版视觉全部由 Godot 基础节点、`Polygon2D`、`Line2D`、`ColorRect`、`Label` 组成。
- 首版只实现一个场地和一个 main scene。
- 首版优先可读、可改、可运行；复杂效果留到后续阶段。
