# Tactical Proxy Strike

`Tactical Proxy Strike` 是一个面向 Godot 4.6.2 的轻量 TPS 训练场 demo。它不追求复刻 `godotengine/tps-demo` 的高质量资产和动画系统，而是保留其最关键的职责拆分：玩家输入与视角控制、第三人称肩后相机、瞄准态射击、敌方感知与开火状态机，以及一个可反复重开的封闭战斗场。

## 首版概念

玩家控制一个蓝色训练代理人，在更大尺寸的矩形训练场中借助掩体清理 4 个巡逻哨兵。场地中央和两翼布置了不同高度的 cover，迫使玩家在移动射击和短暂停火之间切换。相机默认处于较远的肩后追踪位，进入瞄准态后收拢到右肩，并显示准星。为了避免开场就被远端巡逻火力压制，回合开始后的前 3 秒提供部署无敌时间。

## 首版范围

- 核心动词：移动、跳跃、瞄准、射击、清敌。
- 视角：鼠标控制的第三人称肩后相机。
- 玩家：1 个 `CharacterBody3D`，带 100 点生命值、部位伤害判定，以及仅开局生效的部署护盾。
- 敌人：4 个巡逻哨兵，基于视线检测进入瞄准并发射激光。
- 关卡：1 个由 box / cylinder primitive 组成的封闭训练场。
- UI：目标提示、血量条、剩余敌人数、倒计时、状态消息。

## 胜负条件

- 胜利：在倒计时归零前消灭全部 `4` 个哨兵。
- 失败：生命值归零、倒计时归零，或跌出训练场。
- 重开：游戏结束后按 `Space` 或 `Enter`。

## 操作设计

- 默认鼠标捕获，保证 TPS 视角稳定。
- `RMB` 支持短按切换瞄准和长按保持瞄准，沿用参考 demo 的交互思路，但实现上做了轻量化。
- 只有在瞄准状态下才能射击，鼓励玩家在移动和开火之间主动切换节奏。
- `Esc` 用于释放鼠标，方便在桌面环境中调试和切回编辑器。

## 设计约束

- 首版不导入外部角色模型、贴图、字体或音频。
- 首版视觉全部由 Godot 内置 `MeshInstance3D`、primitive、灯光、材质和 `Label` 构成。
- 首版不实现复杂导航、动画树、联机或菜单系统。
- 首版优先保证“能跑、能打、能重开、能继续迭代”；更高保真资产、音效和反馈留给后续版本。
