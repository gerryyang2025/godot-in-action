# Security Policy

## Supported Scope

This repository is currently a Godot learning/demo workspace. Security support applies to original files in this repository, not to local upstream reference caches such as the Godot engine source, official docs, demo snapshots, or editor binaries.

## Reporting a Vulnerability

If you find a vulnerability in original demo code from this repository, please do not publish exploit details in an issue first.

Preferred reporting path:

- Open a GitHub security advisory for this repository if that feature is available.
- If not available, contact the repository owner through their GitHub profile and share a minimal description first.

Please include:

- Affected directory or demo name.
- Godot version used to reproduce.
- Reproduction steps.
- Expected and actual behavior.
- Any relevant logs or screenshots.

## Upstream Godot Issues

If the problem is in Godot Engine itself, official Godot demos, official documentation, or a third-party asset, report it to the corresponding upstream project.
