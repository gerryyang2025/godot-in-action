# Beacon Runner 3D

`Beacon Runner 3D` 是一个 Godot 4.6.2 目标版本的轻量 3D 训练场 demo。玩家控制一个胶囊形探测员，在封闭训练平台中移动和跳跃，收集发光信标，同时躲开沿固定航线巡逻的无人机。

## 首版概念

训练场把 2D demo 的“信标回收”任务升级成 3D 空间演练。玩家需要在一个低墙围出的平台里判断前后、左右和高度，跑向 5 个绿色信标。红色无人机沿两条可读的路径巡逻，逼迫玩家改变路线或跳过小坡。玩家有 3 点护盾，被无人机碰到会短暂无敌并闪烁。目标是在倒计时结束前同步全部信标。

## 首版范围

- 核心动词：移动、跳跃、收集、躲避。
- 视角：第三人称斜俯视跟随相机。
- 玩家：1 个 `CharacterBody3D` 胶囊角色。
- 收集物：5 个同时存在的 `Area3D` 发光信标。
- 障碍：2 个 `Area3D` 巡逻无人机。
- 关卡：1 个 box / cylinder primitive 组成的训练场。
- UI：信标数、护盾数、倒计时、状态提示。

## 胜负条件

- 胜利：在倒计时归零前收集 `5` 个信标。
- 失败：护盾归零、倒计时归零，或掉出训练平台。
- 重开：游戏结束后按 `Space` 或 `Enter`。

## 操作

- 移动：`WASD` 或方向键。
- 跳跃：游戏进行中按 `Space`。
- 开始/重开：未在游戏中时按 `Space` 或 `Enter`。

## 设计约束

- 首版不使用外部模型、贴图、字体或音频。
- 首版视觉全部由 Godot 内置 `MeshInstance3D`、primitive mesh、灯光、材质和 `Label` 组成。
- 首版只实现一个 main scene，不依赖编辑器里手工切换场景。
- 首版优先可读、可测、可继续改；角色动画、导航、模型导入、音频和菜单留给后续。
